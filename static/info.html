¿Cómo funciona SABDIAN?

Arquitectura, flujo de análisis y herramientas utilizadas en el proyecto.

SABDIAN evalúa fragmentos de código o carpetas completas de proyectos combinando métricas estructurales con análisis semántico mediante inteligencia artificial, generando un veredicto claro y una tabla detallada de hallazgos.

Tecnologías empleadas

Función de cada herramienta dentro de la plataforma.

01

Python & FastAPI

Lenguaje principal y framework del backend. Se encargan de recibir las solicitudes de análisis (tanto de código individual como de carpetas de proyecto), exponer las rutas de la API y coordinar el flujo con el módulo analizador.

02

Uvicorn

Es el servidor ASGI que ejecuta la aplicación FastAPI, mantiene el servicio escuchando peticiones HTTP y entrega los archivos del frontend tanto en entorno local como en el despliegue en la nube.

03

Pydantic

Se usa para validar y estructurar los datos que entran a la API (como el bloque de código o el conjunto de archivos de una carpeta), asegurando que cumplan el formato esperado antes de procesarlos.

04

Groq

Es el motor de inferencia de IA que realiza la evaluación semántica del código para detectar señales o patrones asociados a código generado por inteligencia artificial, complementando el análisis del proyecto.

05

GitHub y Render

GitHub guarda el código fuente y el historial de versiones del repositorio, mientras Render compila las dependencias y despliega la aplicación web en línea.

06

HTML, CSS y JavaScript

Conforman la interfaz web con estilo neumórfico (usando tipografías Audiowide e Inter), el interruptor animado, la carga de código o carpetas y la presentación de resultados y hallazgos en tablas.
