¿Qué es SABDIAN?

SABDIAN es una herramienta de análisis de código impulsada por Inteligencia Artificial. Su objetivo es ayudarte a detectar la deuda técnica (código difícil de mantener) y verificar si un bloque de código parece haber sido generado por una IA.

1

Elige tu modo

Usa el interruptor de arriba para analizar un bloque individual o un proyecto completo (carpeta).

2

Sube tu código

Pega el texto o arrastra la carpeta de tu proyecto. Filtramos automáticamente archivos basura.

3

Obtén el veredicto

El sistema evalúa la complejidad, el estilo y la lógica de tu código con IA, dándote una calificación.
