SABDIAN

Sistema Analítico de Barrido y Detección por Inteligencia Artificial Neuronal

SABDIAN es una plataforma híbrida de auditoría de software. No se limita a "leer" el código; ejecuta un riguroso barrido estático multi-lenguaje para extraer métricas de calidad, para luego delegar la evaluación de la arquitectura y lógica de negocio a una red neuronal avanzada.

1

Selecciona el Alcance

Usa el interruptor para elegir entre auditar un bloque individual o realizar un barrido profundo a un proyecto completo.

2

Barrido Estático (Fase 1)

El motor en Python analiza el código sin ejecutarlo. Evalúa la complejidad ciclomática, duplicación, entropía de nombres y detecta malas prácticas.

3

Evaluación Neuronal (Fase 2)

Los resultados del barrido se envían a la IA, que evalúa la semántica del código, la coherencia arquitectónica y emite el veredicto de Deuda Técnica.
